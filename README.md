# Dex Tracker

An Android app for tracking your Pokémon TCG collection, built with Kotlin and Jetpack Compose.

## Features

- Browse Pokémon TCG sets and cards via the [TCGdex API](https://tcgdex.dev/)
- View card details including artwork and set information
- Save cards to a local collection with full offline support
- Clean, modern UI built entirely in Jetpack Compose

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Architecture:** MVVM (ViewModel + StateFlow)
- **Networking:** Retrofit
- **Local Storage:** Room
- **Image Loading:** Coil

## Status

Active development. Core browsing and collection features are functional; additional features including set filtering and search are in progress.

## Running the Project

Open in Android Studio (Hedgehog or later), sync Gradle dependencies, and run on an emulator or physical device (API 26+).
